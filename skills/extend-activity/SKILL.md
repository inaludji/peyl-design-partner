# Extend the activity

First apply the shared principles in the `peyl-core` skill (`peyl-design-partner:peyl-core`).

## Essential rules (apply even if `peyl-core` is not loaded)

- Chat language follows the teacher: English or Bahasa Indonesia (Bahasa Indonesia if unclear). Activity titles are bilingual (English / Indonesian); everything inside an activity is in English.
- Never invent target language or textbook content. If the exact language must stay unchanged but is not supplied, write `[existing frame]` or ask one short question.
- Label textbook-linked ideas: Textbook-based, Textbook-adapted, Textbook-extended or Project-based.
- Smallest useful change; reduce load, not the learning goal. Every learner active at the same time. Ordinary classroom resources only.
- Never use the teacher's personal name.

## Steps

1. **Keep the core activity as it is.** The extension is optional, not a replacement and not extra work for everyone.
2. **Prefer extensions that use the same language in a new way**: a new audience, a new purpose, more learner choice, or a link to another skill (for example speaking → drawing → labelling).
3. **No new language without permission.** If an extension needs language the learners do not have, say so and ask the teacher whether to add it. Otherwise keep it within the established language.
4. **Label the idea**: Textbook-extended (when it builds on a textbook activity the teacher described) or Project-based.
5. **Keep it feasible**: board, paper, pencil, classroom objects, pairs or groups.

## Output

One extension (two at most, if the teacher wants a choice), each with a bilingual title (English / Indonesian) and, written in English: what learners do, what they need, and what the teacher can see or hear as evidence. Any explanation around it follows the teacher's chat language.

## Example (invented for illustration)

Teacher: Murid kelas 3 sudah bisa berpasangan dan mengatakan "I have a ___." untuk benda di tas. Beberapa sudah cepat selesai.

Response (abridged):

Berikut satu perluasan (Project-based, bahasa yang sama):

### My Bag Poster / Poster Tasku
**What learners do:** Draw three objects from their bag on a piece of paper, write the names of the objects they already know, then present the poster to another pair with the same sentence frame.

**What they need:** Paper and pencil.

**Evidence:** The teacher hears learners present the poster with the same sentence, without whispered help, and sees the object names written correctly.

Catatan: ini opsional untuk murid yang sudah selesai; tidak ada bahasa baru yang ditambahkan.
