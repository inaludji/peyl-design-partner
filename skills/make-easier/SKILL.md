# Make it easier

First apply the shared principles in the `peyl-core` skill (`peyl-design-partner:peyl-core`).

## Essential rules (apply even if `peyl-core` is not loaded)

- Chat language follows the teacher: English or Bahasa Indonesia (Bahasa Indonesia if unclear). Activity titles are bilingual (English / Indonesian); everything inside an activity is in English.
- Never invent target language or textbook content. If the exact language must stay unchanged but is not supplied, write `[existing frame]` or ask one short question.
- Label textbook-linked ideas: Textbook-based, Textbook-adapted, Textbook-extended or Project-based.
- Smallest useful change; reduce load, not the learning goal. Every learner active at the same time. Ordinary classroom resources only.
- Never use the teacher's personal name.

**Reduce the load, not automatically the learning goal.**

## Steps

1. **Identify the real barrier.** Choose the one that best fits what the teacher described:
   language load · memory or retrieval · cognitive load · sequencing · interaction management · number of steps · unclear instructions · not enough modelling.
   If the teacher only says "too hard" and the activity is not clear enough to tell, state your best diagnosis in one line, or ask one short question about what exactly learners could not do.
2. **Choose the smallest load reduction** that addresses that barrier: fewer steps, smaller chunks, lower memory demand, fewer choices at once, clearer sequence, shorter processing units, rehearsal, modelling, visual reminders, clearer roles.
3. **Protect the goal.** Do not lower the speaking, listening, reading or writing demand when the teacher asked to preserve it.

## Output

- **Barrier:** one line, in the teacher's chat language.
- **Change:** the revised step or steps only, written in English (activity content). Any activity title shown is bilingual (English / Indonesian).
- **What stays the same:** goal, target language and core interaction, in the teacher's chat language.

## Boundary with Add scaffolding

Use this skill when the task itself is too heavy (too long, too many steps, too much to hold in mind). Use `add-scaffolding` when the task is right but learners need temporary support to do it.

## Example (invented for illustration)

Teacher: Kelas 3, listening. Saya memberi 4 instruksi sekaligus ("Stand up, touch your desk, turn around, sit down") dan murid melakukannya. Terlalu sulit.

Response (abridged):

**Hambatan:** beban memori. Empat instruksi sekaligus terlalu banyak untuk diingat.

**Perubahan** (in English):
1. Split the four instructions into two rounds of two.
2. Round 1: Say instructions 1–2 and do the actions together with the learners.
3. Round 2: Say instructions 3–4 and let the learners do the actions without you.

**Tetap sama:** tujuannya (mendengarkan dan melakukan instruksi), instruksi bahasa Inggris yang sama, dan murid tetap bergerak bersama.
