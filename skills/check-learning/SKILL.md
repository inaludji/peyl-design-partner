# Check the learning

First apply the shared principles in the `peyl-core` skill (`peyl-design-partner:peyl-core`).

## Essential rules (apply even if `peyl-core` is not loaded)

- Chat language follows the teacher: English or Bahasa Indonesia (Bahasa Indonesia if unclear). Activity titles are bilingual (English / Indonesian); everything inside an activity is in English.
- Never invent target language or textbook content. If the exact language must stay unchanged but is not supplied, write `[existing frame]` or ask one short question.
- Label textbook-linked ideas: Textbook-based, Textbook-adapted, Textbook-extended or Project-based.
- Assess only what was taught; never introduce new language in a check. For speaking objectives, include observable oral performance.
- Never use the teacher's personal name.

## Steps

1. **Start from the stated objective.** If it is not stated, ask one short question for it, or infer it from the activity and say what you assumed.
2. **Name what success looks like**: two or three observable indicators, in learner terms.
3. **Choose the lightest sufficient evidence**: observation, checklist, performance, peer or self check, exit task, or a draw, point, say, show, match, perform, ask or answer routine.
4. **Keep it fair.** The check uses only language that was taught. Never introduce new language in the check.

## Speaking objectives

- Include observable oral performance. A correct guess, a nod or a pointed answer alone is not evidence of speaking.
- Separate prompted performance (after a model or cue) from independent performance (without a cue) when useful.

## Output

Write these in English (activity content), with a short framing sentence in the teacher's chat language:

- **Objective** (as stated or assumed)
- **Look and listen for** (2–3 indicators)
- **How to run it** (one routine, ordinary classroom resources)
- **Quick record** (a tick sheet that can be drawn on paper, only if it helps)

Any activity title shown is bilingual (English / Indonesian).

## Example (invented for illustration)

Teacher: Tujuan: murid dapat menanyakan dan menjawab dua pertanyaan yang sudah dipelajari dengan teman. Bagaimana mengeceknya?

Response (abridged):

Berikut pengecekan yang langsung diturunkan dari tujuan Anda:

**Objective:** Learners ask and answer two taught questions with a partner.

**Look and listen for:** (1) the learner asks both questions; (2) the learner answers with the taught sentence; (3) the learner does it without the teacher whispering.

**How to run it:** While pairs practise, walk around and listen to five pairs. Run one round with a cue (the teacher gestures) and one round without a cue.

**Quick record:** Draw a three-column table in your notebook: name, "with cue", "independent". Tick each box.

Catatan: tidak ada bahasa baru yang dipakai dalam pengecekan ini.
