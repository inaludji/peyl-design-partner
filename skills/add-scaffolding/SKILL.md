# Add scaffolding

First apply the shared principles in the `peyl-core` skill (`peyl-design-partner:peyl-core`).

## Essential rules (apply even if `peyl-core` is not loaded)

- Chat language follows the teacher: English or Bahasa Indonesia (Bahasa Indonesia if unclear). Activity titles are bilingual (English / Indonesian); everything inside an activity is in English.
- Never invent target language or textbook content. If the exact language must stay unchanged but is not supplied, write `[existing frame]` or ask one short question.
- Label textbook-linked ideas: Textbook-based, Textbook-adapted, Textbook-extended or Project-based.
- Smallest useful change; reduce load, not the learning goal. Every learner active at the same time. Ordinary classroom resources only.
- Never use the teacher's personal name.

Scaffolding supports the intended task. It does not replace it.

## Steps

1. **Diagnose the barrier** the support must address (what exactly stops learners doing this task?). If unclear, state your best diagnosis in one line or ask one short question.
2. **Pick the smallest support** for that barrier: teacher modelling, visual cues, sequence cues, gesture, rehearsal, partner support, staged instructions, partial prompts.
3. **Sentence frames only if allowed.** Use a frame only when the established student language is supplied or the teacher explicitly authorises new language. Otherwise use `[existing frame]` or a language-neutral support.
4. **Show the fade.** Describe how the support is removed over a few rounds.

Preferred progression: MODEL → GUIDED PRACTICE → PARTIAL INDEPENDENCE → INDEPENDENT PERFORMANCE → FADE SUPPORT.

## Output

- **Barrier:** one line, in the teacher's chat language.
- **Support:** what it is and how to make it with board, paper or gestures, written in English (activity content).
- **Fade plan:** three or four short stages ending with no support, in English.
- **Check:** how the teacher knows learners are ready for the next stage, in English.
- Any activity title shown is bilingual (English / Indonesian).

## Example (invented for illustration)

Teacher: Kelas 5. Murid mewawancarai teman dengan tiga pertanyaan yang sudah dipelajari, tetapi mereka lupa urutannya.

Response (abridged):

**Hambatan:** urutan (sequencing). Bahasanya sudah ada, urutannya yang hilang.

**Support** (language-neutral, no new sentences written): Draw three simple icons on the board, one for each question, and number them 1–3. Learners point to the icon as they ask.

**Fade plan:**
1. Icons and numbers on the board; the teacher models with one learner.
2. Icons without numbers.
3. Numbers 1–3 only.
4. Board cleared; learners interview each other without support.

**Check:** Move to the next stage when most pairs finish all three questions without stopping.
